A LETTER IN TWO THREADS
=======================

Open index.html in Chrome, Edge, Safari or Firefox. Use the internet the first time so the handwriting font loads.

Open early to preview: tap the wax seal 5 times. Before 14 Oct 2026 (IST) the letter stays sealed.

To edit: open index.html in any text editor and find the block that starts with "const CONFIG = {".
  her / his        the two names
  unlock           when the letter opens (2026-10-14T00:00:00+05:30)
  blocks           every paragraph. Text in [square brackets] is a slot for your own words.
  { t: "page" }    starts a new page
  { t: "art", k: "ranunculus" | "rose" | "wreath" | "moon_vine" | "bouquet", side: "l" | "r" }   a drawing

To share: upload the folder to any free host (Netlify Drop, GitHub Pages) and send her the link.


PHOTO SECTION
=============
The letter now includes a four-photo memory section with a scrapbook-style layout.
Replace these placeholder files with your own photos, keeping the same filenames:
  photos/photo1.jpg
  photos/photo2.jpg
  photos/photo3.jpg
  photos/photo4.jpg

You can also change the photo captions inside the const CONFIG = { ... } block in index.html.
The photos are displayed between the personal-memory section and the two-thread story.
